## PHPUnit 10 to 11

Source: `ChangeLog-11.0.md`, checked by running tests against PHPUnit 10.5.65 and 11.5.56. PHPUnit 11 needs PHP 8.2. 11 is mostly a deprecation release: it tells you everything 12 removes. Go to 11.5 and make it clean; that is the 12 upgrade done in advance.

### Hard Failure: Data Providers Must Be `public static`

Deprecated in 10 ("Data Provider method X::ids() is not static"), an error in 11: "The data provider specified for X::test... is invalid". The test isn't run and **the test count drops**, so compare counts against the baseline rather than only looking for red. Make providers `public static`, with no parameters. Rector: `StaticDataProviderClassMethodRector`, `PublicDataProviderClassMethodRector`.

### Deprecated in 11, Removed in 12

Run `vendor/bin/phpunit --display-all-issues` and clear every "PHPUnit deprecation".

**Doc-comment metadata.** "Metadata found in doc-comment for method X::y(). Metadata in doc-comments is deprecated and will no longer be supported in PHPUnit 12." Convert `@test`, `@dataProvider`, `@depends`, `@group`, `@covers`, `@uses`, `@testWith`, `@requires`, `@runInSeparateProcess` and the rest to attributes in `PHPUnit\Framework\Attributes`.

**Incorrect:**

```php
/**
 * @test
 * @dataProvider recipients
 */
public function it_sends(string $to): void
```

**Correct:**

```php
use PHPUnit\Framework\Attributes\DataProvider;
use PHPUnit\Framework\Attributes\Test;

#[Test]
#[DataProvider('recipients')]
public function it_sends(string $to): void
```

Rector: `->withAttributesSets(phpunit: true)` or `->withComposerBased(phpunit: true)`. `@covers ClassName` becomes `#[CoversClass(ClassName::class)]` on the class; method-level `@covers` has no one-to-one attribute (`#[CoversMethod]` exists from 11.0; check what Rector produced).

**`expects()` on stubs.** "Expectations configured on test doubles that are created as test stubs are no longer verified since PHPUnit 10." A `createStub()` with `->expects($this->once())` never verified anything. Either the expectation matters (use `createMock()`) or it doesn't (drop `expects()`). In 12 `expects()` doesn't exist on stubs.

**Return stub helpers on `TestCase`.**

| Deprecated | Use |
|---|---|
| `->will($this->returnValue($v))` | `->willReturn($v)` |
| `->will($this->onConsecutiveCalls($a, $b))` | `->willReturnOnConsecutiveCalls($a, $b)` or `->willReturn($a, $b)` |
| `->will($this->returnCallback($fn))` | `->willReturnCallback($fn)` |
| `->will($this->returnValueMap($map))` | `->willReturnMap($map)` |
| `->will($this->returnArgument($i))` | `->willReturnArgument($i)` |
| `->will($this->returnSelf())` | `->willReturnSelf()` |

**Test-double creation helpers.** `getMockForAbstractClass()`, `getMockForTrait()`, `getObjectForTrait()`, `getMockFromWsdl()`, `createTestProxy()`, and on `MockBuilder`: `addMethods()`, `getMockForAbstractClass()`, `getMockForTrait()`, `enableProxyingToOriginalMethods()`, `allowMockingUnknownTypes()`, `enableAutoload()`, `enableArgumentCloning()` and their opposites. For abstract classes and traits, `createMock()` / `getMockBuilder()->onlyMethods([...])` on an interface or a small concrete test class; `addMethods()` (mocking methods that don't exist) has no replacement, so the code under test usually needs an interface: report it rather than changing production code.

**Also:** `TestCase::iniSet()` and `setLocale()`; `assertStringNotMatchesFormat()` and `assertStringNotMatchesFormatFile()`; doubling a type with a method named `method`.

### New in 11 That Helps

- `expectUserDeprecationMessage()` / `expectUserDeprecationMessageMatches()`: what `expectDeprecation()` used to do.
- `#[TestWith]` with named data sets, named arguments from providers.
- `--display-phpunit-deprecations` and `--display-all-issues`.

### Late 11.5 Soft Deprecations

`assertContainsOnly()`, `assertNotContainsOnly()`, `containsOnly()` and `Assert::isType()` were soft-deprecated in 11.5, hard-deprecated in 12.0 and removed in 13.0. 11.5 added the replacements: `assertContainsOnlyString()`, `assertContainsOnlyInt()`, `assertContainsOnlyArray()` and the other per-type variants, `assertContainsNotOnly*()` for the negations, `assertContainsOnlyInstancesOf()` for classes, and `isString()`, `isInt()`, ... instead of `isType('string')`. The per-type methods don't exist before 11.5, so replace on 11.5, not earlier. Rector: `AssertContainsOnlyMethodCallRector`, `AssertIsTypeMethodCallRector`.

### Laravel and Pest

Laravel 11 and 12 support PHPUnit 10.5, 11 and 12; Laravel 10 does not support 11. In Pest projects this step is Pest 3 (`pest/pest-upgrades.md`).
