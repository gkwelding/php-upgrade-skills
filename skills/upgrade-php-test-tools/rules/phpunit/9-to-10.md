## PHPUnit 9 to 10

Source: `ChangeLog-10.0.md`, checked by running tests against PHPUnit 9.6.37 and 10.5.65. PHPUnit 10 needs PHP 8.1. It is the biggest of the steps: the runner, the event system and the configuration format all changed.

### Order

1. Bump to `^10.5`, run `vendor/bin/phpunit --migrate-configuration` (`configuration.md`).
2. Run Rector's composer-based PHPUnit set (`shared/rector.md`). Its 10.0 rules only activate once 10 is installed.
3. Fix what's left by hand, run with `--display-all-issues`.

Annotations still work in 10 without any notice; attributes (`#[Test]`, `#[DataProvider]`) exist from 10.0. Converting now is optional but saves the 11 step.

### `withConsecutive()` Is Removed

**Incorrect** (fatal on 10: undefined method):

```php
$mailer->expects($this->exactly(2))
    ->method('send')
    ->withConsecutive(['a@example.com'], ['b@example.com'])
    ->willReturn(true);
```

**Correct** (runs on 10, 11, 12 and 13):

```php
$matcher = $this->exactly(2);

$mailer->expects($matcher)
    ->method('send')
    ->willReturnCallback(function (string $to) use ($matcher): bool {
        match ($matcher->numberOfInvocations()) {
            1 => $this->assertSame('a@example.com', $to),
            2 => $this->assertSame('b@example.com', $to),
        };

        return true;
    });
```

`withConsecutive()` compared arguments with `IsEqual` (loose). Use `assertEquals()` instead of `assertSame()` for object arguments to keep that meaning. `numberOfInvocations()` exists from 10.0. On PHPUnit 13 there is also `withParameterSetsInOrder()` (`12-to-13.md`).

### Other Removals

| Removed in 10 | Replacement |
|---|---|
| `at()` matcher | `exactly()` + `numberOfInvocations()` as above |
| `MockBuilder::setMethods()`, `setMethodsExcept()` | `onlyMethods()` for existing methods (`addMethods()` for non-existent ones is deprecated in 11) |
| `expectDeprecation()`, `expectNotice()`, `expectWarning()`, `expectError()` and their `*Message()` / `*MessageMatches()` variants | none in 10; `expectUserDeprecationMessage()` from 11.0. Test the behaviour, or catch an `ErrorException` thrown by a test-local error handler |
| `assertObjectHasAttribute()`, `assertClassHasAttribute()` and other property assertions | `assertObjectHasProperty()` (10.1+), or `property_exists()` with `assertTrue()` |
| `assertRegExp()`, `assertFileNotExists()`, `assertDirectoryNotExists()` (deprecated in 9) | `assertMatchesRegularExpression()`, `assertFileDoesNotExist()`, `assertDirectoryDoesNotExist()` |
| Prophecy integration (`$this->prophesize()`) | `phpspec/prophecy-phpunit` and its `ProphecyTrait` (ask before adding it) or PHPUnit doubles |
| `TestListener`, `<listeners>` in XML, test hooks | Extensions using the event system (`<extensions><bootstrap class="..."/>`) |
| `getMockClass()` | `createMock()` / `getMockBuilder()` |
| `--verbose`, `--debug`, `--printer`, `--repeat`, `--extensions` | `--display-*` options; printers and listeners become extensions |

`TestCase` and `Assert` public methods are `final` in 10; test classes overriding `assertEquals()` and friends must rename their helper.

### Data Providers

Non-static, non-public or parameterised provider methods are deprecated in 10 and removed in 11. Make them `public static` now. A provider that used `$this` (factories, `$this->createMock()` inside the provider) has to be rewritten: build plain data in the provider and create objects in the test.

### Behaviour Changes

- Tests no longer stop at the first `E_DEPRECATED` / `E_NOTICE` / `E_WARNING` from tested code; they continue and the issue is reported. Tests that relied on `convertDeprecationsToExceptions` / `convertNoticesToExceptions` (removed) to fail now pass with an issue listed: read `--display-all-issues`.
- Global variables defined in the bootstrap script are no longer globals in tests; use `$GLOBALS['name'] = ...` there.
- The runner stops on failure only with `--stop-on-failure` / `--stop-on-defect`, etc.

### Laravel and Pest

Laravel 10 supports PHPUnit 10 (`laravel/framework` 10 conflicts with PHPUnit 11). Pest projects don't require `phpunit/phpunit` directly: Pest 2 is the PHPUnit 10 step (`pest/pest-upgrades.md`).
