## Laravel 11 to 12

Source: the official 12.x upgrade guide, checked against `laravel/framework` 11.57 and 12.69. A small release for most apps; the risky items are default changes, not removed APIs.

### Dependencies

PHP 8.2 (unchanged). In `composer.json`: `laravel/framework` `^12.0`. The guide also lists `phpunit/phpunit` `^11.0` and `pestphp/pest` `^3.0`, but Laravel 12's test layer still supports PHPUnit 10.5. If PHPUnit or Pest is a major behind, do it as its own step (`upgrade-php-test-tools`, if installed), before or after this one, not mixed in.

**Carbon 3 is required.** Laravel 12 requires `nesbot/carbon ^3.8.4`. If the project stayed on Carbon 2 during the 11 step, this step includes Carbon 3: read `carbon-3.md` and grep the `diffIn*` calls before updating.

`laravel/tinker` stays `^2.x` for 12 (Tinker 3 comes with 13).

### Silent Default Changes

**`HasUuids` now generates UUIDv7** (time-ordered). Previously ordered UUIDv4. Existing rows are untouched; new IDs are a different version. Code or tests that check the version (a regex on the version digit, `uuid:4` validation rules, external systems expecting v4) break. To keep v4:

```php
use Illuminate\Database\Eloquent\Concerns\HasVersion4Uuids as HasUuids;
```

`HasVersion7Uuids` was removed; use `HasUuids`.

**`local` disk root moved to `storage/app/private`**, but only when the app's `config/filesystems.php` doesn't define a `local` disk. Most apps define it; check. If it isn't defined, files written before the upgrade are no longer found by `Storage::disk('local')`. Define the disk explicitly with the old root rather than moving files.

**`image` validation rejects SVG** unless allowed: `'image:allow_svg'` or `File::image(allowSvg: true)`. Upload forms that accepted SVG logos start returning 422.

**The container respects default values of constructor parameters.** `public function __construct(public ?Carbon $date = null)` resolved via the container now gets `null`, where 11 injected a `Carbon` instance.

**Multi-schema inspection.** `Schema::getTables()`, `getViews()`, `getTypes()` return all schemas; `Schema::getTableListing()` returns schema-qualified names (`main.users`) by default. Pass `schema:` / `schemaQualified: false` to keep the old shape.

**`Concurrency::run()` with string keys** returns results keyed by those keys.

**`$request->mergeIfMissing()`** treats dot notation as nested keys.

**Route name collisions**: uncached routing now matches the first route registered with a given name (was the last), matching cached routing.

### Low-Level Changes

Only relevant to custom database drivers, grammars or packages: `Blueprint` and `Grammar` constructors now take the `Connection`; `Grammar::setConnection()` and `Connection::withTablePrefix()` were removed. `DatabaseTokenRepository` takes `$expires` in seconds.

### Rector

`withComposerBased(laravel: true)` adds `Request::get()` to `input()` renames and optional modernisation (`scopeX()` to `#[Scope]` from 12.4). See `shared/rector.md`.
